Stackview manual

Stackview is a website that shows every PCB of our 3U satellite: schematics, board layouts,
3D models and parts lists. It works on a laptop or a phone. You don't need KiCad to use it.

Website: https://padamsarda.github.io/stackview/

This manual has three parts. Read only the one you need.

  1. I want to look at a board or review it. Read Part A. Takes 2 minutes, nothing to install.
  2. I design a board and want to share my work. Read Part B. Takes 15 minutes, once.
  3. Something isn't working. Read Part C.

Part A: Looking at boards (no installation)

Open a board

  1. Open the website link above.
  2. You will see a list of branches. Click main. That is the official, combined design. (Other entries like wip/padam are someone's work in progress.)
  3. You now see one card per board. The coloured dot shows when it was last updated: green = this week, yellow = within 3 weeks, red = older.
  4. Click a board.

The tabs at the top

  • Schematic: the circuit drawing.
  • PCB: the board layout. Use Top / Bottom to flip the board. Tick the boxes under Layers to show or hide copper, silkscreen and other layers.
  • 3D: the finished board in 3D. You can rotate it, zoom and move it (see Rotating the 3D view below).
  • BOM: the parts list. Type in the filter box to search it.
  • Files: downloads (PDF of the schematic, parts list as a spreadsheet, and more).

Finding a part or a signal

Type in the Find box, for example U3, C12, 470nF or I2C_A_SDA. Click a result and
the view jumps there and puts a pink circle around it.
On a phone, tap ☰ at the top first to open the Find box.

The 3D stack

Press 3D Stack on the home page to see every PC/104 board stacked together, the way they sit
in the satellite, joined by their stack-through headers.

  • Rotate, zoom and move the same way as in a board's 3D tab (see below).
  • Change the order: in the side panel, drag a board's row up or down, or use ▲ ▼. The list is top to bottom, the same as the stack.
  • Hide a board: untick its box.
  • Nudge a board up or down: use its ↕ slider (±3 mm). Double-click the slider to reset it.
  • Spacing: Board pitch is the normal distance between boards (15.24 mm). Spread pulls the boards apart so you can see between them.
  • Click a board's name (in the list or in 3D) to zoom to it.
  • Copy link gives you a link to exactly this stack, so others see the same order and settings. Reset goes back to the default (folder order).

Boards are lined up on the PC/104 connector footprint, so a board only appears here once its PCB
has that footprint.

Leaving a review comment

  1. Zoom to the spot you want to talk about.
  2. Press 💬 Comment here (on a phone it's just the 💬 button).
  3. A GitHub page opens with the board name and a link to the exact spot you were looking at already filled in. Write your comment under the line that says so, and press Submit new issue.

You need a GitHub account that is a member of the team-anant organisation. Ask the team lead
if you don't have one.

Part B: Sharing your KiCad work (designers)

You keep working in KiCad exactly as before. When you want others to see your board, you
double-click one file. A few minutes later your board appears on the website.

One-time setup (about 15 minutes)

1. Get access. Make a GitHub account at github.com and ask the team lead to add you to the
team-anant organisation.

2. Install Git. Download Git for Windows from https://git-scm.com/download/win and install
it. Click Next on every screen. The default choices are fine.

3. Get a copy of the design folder.
Pick a place on your laptop, for example your Desktop. Open that folder in File Explorer,
right-click an empty area, choose Open Git Bash here (on Windows 11 it may be under
Show more options), then paste this and press Enter:

git clone https://github.com/team-anant/3U-EM-PCB.git

A browser window may ask you to sign in to GitHub. Do it. You now have a folder called
3U-EM-PCB with every board inside it.

Already have the folder from before (for example through GitHub Desktop)? Skip this step and use that folder.

4. Design your board inside that folder. Your board lives in its own subfolder, for example
8.BatteryBoard or 5.ADCS. Open the .kicad_pro file in there with KiCad.

Every time you want to share (10 seconds)

  1. Save in KiCad (both the schematic and the PCB editor).
  2. Open the 3U-EM-PCB folder, then the stackview folder, and double-click sync.bat.
  3. The first time only, it asks:
    Your short name. Type something like padam and press Enter.
    Which folder is yours. Type the number next to your board and press Enter.
  4. It asks "What changed?". Type a few words, like added USB connector, or just press Enter.
  5. It says Done. Wait about 5–10 minutes, then open the website. Your branch is listed as wip/<your name>.

Push unfinished work. That's normal and expected. It's how others can help you early.

sync.bat only ever uploads your own board folder. It can't change anyone else's board, and
it doesn't change anything on your laptop.

To change your name or folder later, run sync.bat and type C when it asks.

When your board is ready to become official

  1. Go to https://github.com/team-anant/3U-EM-PCB
  2. GitHub usually shows a yellow bar: "wip/yourname had recent pushes" → Compare & pull request. If it doesn't: click Pull requests → New pull request → set compare to wip/yourname.
  3. Write a title like "Battery board ready for review" and press Create pull request.
  4. Teammates review it and leave comments. When it's approved, it's merged into main.

Part C: When something goes wrong

My board isn't on the website / still shows the old version.
Wait 10 minutes and refresh the page. Then check
https://github.com/team-anant/3U-EM-PCB/actions: a yellow dot means it's still building, and a
red ✗ means the build failed. Click the red ✗ and send a screenshot to the maintainer.

The board page says "Export failed".
KiCad couldn't open the file. Open the board in KiCad on your laptop, fix any error it shows,
save, and run sync.bat again.

sync.bat says "Nothing new since your last sync".
You haven't saved anything new. Save in KiCad and run it again.

sync.bat says "Git is not installed".
Do step 2 of the one-time setup, then restart your laptop.

sync.bat asks for a GitHub login, or says "permission denied".
Sign in when the browser opens. If it still fails, ask the team lead whether you've been added to
team-anant.

sync.bat says "KiCad still has files open".
This is just a reminder. Make sure you saved, then it's fine.

The 3D view is blank or slow.
Use the Top / Bottom pictures instead. The interactive model needs a reasonably new phone
and Wi-Fi.

For the maintainer

  • Board list: stackview/boards.toml. Add a [[board]] block for a new board.
  • How it works and one-time hosting setup: stackview/README.md.
  • The website is rebuilt on every push to any branch. A branch's preview is removed when the branch is deleted.
